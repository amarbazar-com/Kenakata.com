কীভাবে গিটহাব (GitHub)-এ এই ওয়েবসাইট হোস্ট করবেন?

💡 সুবিধা: GitHub Pages ব্যবহার করে আপনি একদম বিনামূল্যে আপনার অনলাইন শপের ওয়েবসাইটটি লাইভ করতে পারবেন!
  1. গিটহাব অ্যাকাউন্ট তৈরি করুন: প্রথমে github.com এ গিয়ে একটি ফ্রি অ্যাকাউন্ট খুলুন।
  2. নতুন রিপোজিটরি (Repository) তৈরি করুন: GitHub-এ গিয়ে উপরে ডান পাশে "+" আইকনে ক্লিক করে "New repository" সিলেক্ট করুন। রিপোজিটরির একটি নাম দিন (যেমন: amar-bazar) এবং "Public" সিলেক্ট করে "Create repository" তে ক্লিক করুন।
  3. ফাইল আপলোড করুন: এই ওয়েবসাইটের সম্পূর্ণ কোডটি আপনার কম্পিউটারে index.html নামে সেভ করুন। এরপর গিটহাব রিপোজিটরিতে "uploading an existing file" লিংকে ক্লিক করে আপনার index.html ফাইলটি ড্রাগ/আপলোড করুন এবং "Commit changes" চাপুন।
  4. GitHub Pages অ্যাক্টিভ করুন: আপনার রিপোজিটরির Settings ট্যাবে যান ➔ বাম পাশের মেনু থেকে Pages এ ক্লিক করুন ➔ Branch অপশনে main অথবা master সিলেক্ট করুন এবং Save বাটনে চাপুন।
  5. আপনার ফ্রি ওয়েবসাইট লিংক পেয়ে যান: ১-২ মিনিট পর পেজটি রিফ্রেশ করলে আপনি আপনার ওয়েবসাইটের লাইভ লিংক পেয়ে যাবেন (যেমন: https://yourusername.github.io/amar-bazar)।

ডাটা কিভাবে কাজ করে?

আপনার যুক্ত করা পণ্য এবং কাস্টমারদের অর্ডার ব্রাউজারের LocalStorage-এ সংরক্ষিত থাকে। এডমিন প্যানেল থেকে আপনি যেকোনো সময় পণ্য পরিবর্তন, নতুন পণ্য যুক্ত বা কাস্টমারদের ফেসবুক আইডি ও ঠিকানা দেখতে পারবেন!
